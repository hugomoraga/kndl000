¿Qué se conserva cuando algo se repite?

Una pregunta abre varios territorios. Este primer trazo reúne materiales que la hacen cambiar de sentido; deja espacio para lo que todavía no conecta.

La traza cian recoge una frase de Rastros: memorias que se fragmentan por procesos que se automatizan. Entre persistencia y desgaste aparece otra tensión: conservar una forma mientras se consume parte de su potencia.

El mapa puede cambiar de pregunta.

Cómo se conecta el contenido en Rizoma

La exploración es el núcleo: lee obras del corpus, comparte nodos con otras derivas, se sostiene en anexos, registra cortes y se fija en una lámina fechada. El aparato tiene cinco tipos: corrección, fuente, concepto, objeción y derivación. El banco es el proceso; Git es la memoria.
